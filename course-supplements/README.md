# Course Supplements

这个目录保存外部课程的专题补充层。它服务于 Stanford CS229 主线，而不是建立第二套机器学习课程仓库。

补充层的边界：

* CS229 仍然是主课程骨架。
* 外部课程只在能加深某个 CS229 节点时进入仓库。
* 补充模块按主题组织，不按外部课程 lecture 编号重建主线。
* coursework mapping 只用于跟踪可选练习来源，不是答案空间。
