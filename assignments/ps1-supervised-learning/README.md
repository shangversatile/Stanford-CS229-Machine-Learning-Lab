## Local Layout

* `official/ps1.pdf`: archived PS1 assignment handout.
* `official/src/`: archived PS1 starter code.
* `official/data/`: archived PS1 datasets.
* `official/environment.yml`: archived coding environment file from the
  problem-set distribution directory.
* `official/problem-sets-README.md`: archived setup README from the
  problem-set distribution directory.
* `attempts/`: independent student attempts only.
* `mistake-log.md`: mistake analysis after attempting the assignment.
* `reflection.md`: public-safe assignment reflection.

## Excluded Materials

The archive also contains `problem-sets-solutions/PS1`; that directory was
explicitly excluded. No solution keys, solved code, unofficial solved
notebooks, or generated answers should be added here.

The archive includes PS1 notebooks in `problem-sets/PS1`. They are not included
in `official/` because their status as original 2018 Piazza distribution files
was not independently confirmed during this import.

## Formal Workflow

Lecture learning
-> Stanford official problem set at the appropriate course checkpoint
-> independent attempt
-> mistake analysis
-> reflection
-> next lecture

Current checkpoint:

* Lecture 4: complete.
* PS1: ready / in progress.
* Lecture 5 note: complete first-pass research-level note.
* Lecture 5 interactive study: in progress.

## Completion Standard

The PS1 gate is complete when:

* the official handout has been read from `official/ps1.pdf`;
* an independent attempt is recorded under `attempts/`;
* derivation and implementation workplans are updated from the attempt;
* `mistake-log.md` is updated;
* `reflection.md` contains a public-safe reflection;
* no solutions or solved notebooks have been added.
