# Math Derivations

This directory records derivations for core CS229 algorithms. The files are grouped by lecture and numbered in the order they should usually be read.

Cross-lecture companions are kept in one canonical location. For example, probability/likelihood foundations live under Lecture 1, but Lecture 2 and Lecture 3 notes still link to those files when they are needed.
